# Flarient Constellation

> Open-source space weather intelligence — powered by NOAA and NASA data, distributed via GitHub.

[**Flarient**](https://flarient.com) is a space decision intelligence platform that translates raw space weather data into actionable insights for aurora chasers, ham radio operators, satellite operators, and anyone curious about what the Sun is doing today.

This GitHub organization hosts the **Flarient Constellation** — a network of open-source projects that fetch, process, and distribute space weather data at zero cost.

---

## Constellation Projects

| Project | Description |
|---------|-------------|
| [flarient-podcast](https://github.com/flarientglobal/flarient-podcast) | Daily AI-generated space weather podcast hosted by Ollie |
| [flarient-constellation](https://github.com/flarientglobal/flarient-constellation) | GitHub-native space weather distribution network |
| [flarient-event-ledger](https://github.com/flarientglobal/flarient-event-ledger) | Public, versioned record of significant space weather events |
| [flarient-space-calendar](https://github.com/flarientglobal/flarient-space-calendar) | Auto-updating space weather calendar with ICS feed |
| [flarient-aurora-badges](https://github.com/flarientglobal/flarient-aurora-badges) | Personalised aurora chance badges for cities worldwide |
| [aurora-station](https://github.com/flarientglobal/aurora-station) | Forkable personal aurora monitoring station with free alerts |
| [space-weather-action](https://github.com/flarientglobal/space-weather-action) | Reusable GitHub Action for CI/CD space weather checks |
| [space-weather-forecast-benchmark](https://github.com/flarientglobal/space-weather-forecast-benchmark) | Open benchmark comparing human vs AI forecasting accuracy |
| [flarient-notebooks](https://github.com/flarientglobal/flarient-notebooks) | Reproducible Jupyter notebooks for space weather research |

## Data Sources

All projects use public data from:

- **NOAA** Space Weather Prediction Center (SWPC)
- **NASA** DONKI (Database Of Notifications, Knowledge, Information)
- **NASA JPL** CNEOS (Center for Near-Earth Object Studies)
- **GFZ** German Research Centre for Geosciences

---

## Cost

**Zero.** All constellation projects run on free tiers:

- GitHub Actions (free for public repos)
- GitHub Pages (free)
- GitHub Releases (free, 2GB storage)
- NOAA/NASA APIs (free, public)
